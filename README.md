# Portfólio — José Wellington Júnior

Landing page original inspirada na direção visual do modelo Lora (sem utilizar os seus ficheiros proprietários), em azul, desenvolvida com Next.js e TypeScript.

## Iniciar

```bash
npm install
npm run dev
```

Abrir http://localhost:3000.

## Personalizar

- Projetos: editar o array `projects` em `app/page.tsx`. O campo `url` deve receber o link público da demo ou do repositório.
- Fotografia: `public/profile.png`.
- CV: `public/cv.pdf`.
- LinkedIn: substituir `https://www.linkedin.com/` pelo endereço do perfil pessoal.
- GitHub: confirmar o username `jwellingtonjuni` antes de publicar.

## Publicar na Vercel

Criar repositório no GitHub, enviar os ficheiros e importar o repositório em vercel.com. Framework: Next.js. Sem variáveis de ambiente necessárias para esta versão.

## Nota

Os projetos são descritos a partir do CV fornecido e do histórico de desenvolvimento. Links de projetos individuais não foram inventados; devem ser preenchidos quando conhecidos.
